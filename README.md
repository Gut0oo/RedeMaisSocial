# 🔹Projeto Rede Mais Social 
*** 

## 🔹Descrição: 
Sistema para avaliadores observarem o perfil de voluntários, com acesso às suas informações pessoais, áreas de interesse e habilidades.  

Antes de qualquer avaliação, o sistema permite que o **candidato se cadastre no App**, preenchendo suas informações pessoais, interesses e habilidades, e se afiliando à plataforma. A partir daí, os avaliadores podem acessar os perfis, avaliar e recomendar voluntários adequados para ONGs com base nas habilidades e interesses observados.
